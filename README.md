# Ci-rec
씨미 레코더

씨미녹화는 Codex를 이용해 만든 
ci.me 라이브 방송 녹화 Windows용 프로그램입니다.

채널 URL을 추가하고 감시 시작을 누르면, 설정한 주기마다 방송 상태를 확인합니다.
방송이 시작되면 선택한 화질로 자동 녹화하고, 방송이 끝나면 mp4 파일로 마무리 저장합니다.

주요 기능
- ci.me 라이브 채널 자동 감시
- 방송 시작 시 자동 녹화
- 360p~2160p 화질 선택
- 녹화 시간, 파일 용량, 변환 진행률 표시
- 저장 폴더 선택
- 채널 목록 저장
- 다크모드 지원
- ffmpeg 내장
- 단일 exe 실행

주의사항
- 녹화 중에는 .part.ts 파일로 저장되고, 방송 종료 후 mp4로 변환됩니다.
- mp4 변환 중에는 임시로 ts 파일과 mp4 파일이 동시에 존재하므로, 녹화 파일 크기의 약 2배 정도 여유 공간이 필요할 수 있습니다.
- 프로그램이 강제 종료되거나 PC가 꺼지면 mp4 변환 전의 .part.ts 파일이 남을 수 있습니다.
- 방송 플랫폼 구조가 변경되면 녹화가 정상 작동하지 않을 수 있습니다.

FFmpeg는 FFmpeg 프로젝트의 상표이며, FFmpeg 자체 라이선스 조건에 따라 배포됩니다.  
이 프로그램에 포함된 FFmpeg 실행 파일은 사용된 FFmpeg 빌드의 라이선스 조건을 따릅니다.

## 서드파티 고지

이 프로그램은 영상 녹화 및 mp4 변환을 위해 FFmpeg를 사용합니다.

FFmpeg는 이 프로젝트에서 개발한 프로그램이 아닙니다.  
FFmpeg와 관련된 권리 및 라이선스 조건은 FFmpeg 프로젝트 또는 사용된 FFmpeg 바이너리 배포자에게 있습니다.

이 프로그램을 재배포하는 경우, 포함된 FFmpeg 실행 파일의 라이선스 조건을 확인하고 준수해야 합니다.
